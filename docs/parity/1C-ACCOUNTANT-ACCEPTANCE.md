## 4. Скидки
Сейчас скидка в mapping v2 не передаётся отдельным полем. Строка допустима только если `lineTotal = qty × unitPrice` (округление HALF_UP до 2 знаков) без скрытой скидки; иначе причины `DISCOUNT` / `QTY_X_PRICE_MISMATCH` → экспорт отклоняется целиком. Вопрос: как 1С должна получать скидку — отдельная графа %, сумма скидки, или цена уже со скидкой? ____

## 5. НДС (критично)
Сейчас строка с ненулевой `vatRate` отклоняется (причина `VAT`): mapping v2 не содержит ставки и суммы НДС, и молча отдать сумму без НДС означало бы неверный документ в 1С. **Следствие: для компаний-плательщиков НДС большинство документов не экспортируются в CSV/XML — mapping v2 непригоден, нужен mapping v3 с НДС. Это блокер релиза бухгалтерской интеграции.** Нужно от бухгалтера: ставки, цена с НДС/без, как раскладывать сумму (НДС сверху / в том числе), графы в 1С: ____

## 6. Единицы и коды
В v2 qty всегда в базовой единице, цена за базовую единицу. Если заказ был в упаковке (qtyInBaseUnit ≠ 1) → причина `UNIT`, экспорт отклоняется. Вопросы: единица в 1С = базовая или упаковка? коды номенклатуры/контрагента: источник и уникальность? ____

## 7. Сверка (обязательна на пилоте)
Для 5–10 документов сверить Velto ↔ 1С: цена, количество, сумма строки, итог документа. Допуск 0,00.
- Правило Velto: `lineTotal = round_HALF_UP(qty × unitPrice, 2)`; итог документа = `Invoice.total`, расхождение суммы строк и итога → `TOTAL_MISMATCH`, отклонение.
- Пример HALF_UP: qty 3,333 × цена 1,50 = 4,9995 → 5,00 (не 4,99 и не банковское округление). qty 0,5 × 0,05 = 0,025 → 0,03.
- Округляет ли 1С так же (построчно, HALF_UP)? Совпали ли суммы на образцах? ____

## 8. Защита от дублей при загрузке (что есть в коде)
- Каждый документ несёт стабильный UUID (`Ид` = Invoice.id / Payment.id), не меняется при повторных выгрузках — ключ дедупликации на стороне 1С. **Будет ли 1С использовать его (поиск по внешнему ID)? Это нужно подтвердить и реализовать на стороне загрузки в 1С: ____**
- Экспорт-задание (ExportJob) с SHA-256 файла, периодом, версией mapping, числом записей; ключ файла детерминирован (повтор перезаписывает, не плодит). Создание защищено Idempotency-Key. Лимит одновременных активных экспортов.
- Только закрытые дни (период до «вчера»), ACK однократный.
- Velto не импортирует из 1С; повторная загрузка того же файла в 1С без проверки по `Ид` дубли создаст.

## 9. Как бухгалтер подтверждает загрузку в Velto (ACK, ADR-030)
1. `/export/1c`: явно выбрать формат (CSV или XML; EXCEL — только реестр) и период, создать.
2. Статус GENERATED → скачать файл, взять SHA-256 (заголовок `X-Content-SHA256`/экран).
3. Загрузить файл в 1С вручную.
4. В Velto: ACK `ACCEPTED` или `REJECTED` + SHA-256 файла (должен совпасть, иначе ошибка). `REJECTED` требует комментарий ≥ 3 символов. Статусы: ACCOUNTING_ACCEPTED / FAILED_REVIEW. Один раз, повтор → 409.
5. EXCEL ACK не принимает: 409 `1C_EXPORT_REGISTER_NOT_ACKNOWLEDGEABLE` (файл помечен «Не для импорта в 1С»).
